# Рандомайзер 🎰

Простий сайт-рандомайзер, зроблений для української твіч-спільноти. Ідея проста: вводите список ігор (чи будь-яких варіантів), а сайт випадково визначає переможця — через слот-машину, колесо фортуни або батл-рояль з кульками.

## Кому це можна

Абсолютно будь-кому. Користуйтеся безкоштовно як завгодно. Єдине: якщо використовуватимете сайт на стрімі, буду вдячний, якщо згадаєте мене та мій канал «OldWizzz».

Якщо хочете взяти цей код за основу і зробити свою версію — будь ласка, це вітається. Єдине прохання: **змініть хоча б дизайн**, щоб ваша версія не була просто копією один-в-один, а мала своє обличчя.

## Що є на сайті

- **Список ігор** (`index.html`) — додаєте варіанти, вказуєте кількість копій (= більше шансів на перемогу), можна зберігати й швидко відновлювати останні списки.
- **Розіграш** (`draw.html`) — три вигляди на вибір:
  - 🎰 **Слот-машина** — класична рулетка з варіантами.
  - 🎡 **Колесо** — кожна копія гри — окремий сектор; після зупинки можна вирішити, прибрати варіант чи залишити його в грі.
  - ⚔️ **Батл-рояль** — кожна гра стає кулькою зі своїм HP (100 + 5 за кожну копію понад першу), кульки штовхаються й б'ються, поки не лишиться одна.
- **Twitch-інтеграція** — можна увійти через Twitch і дати глядачам додавати варіанти в список за бали каналу.

## Локальна перевірка Twitch

1. У [Twitch Developer Console](https://dev.twitch.tv/console/apps) у налаштуваннях цього застосунку додайте OAuth Redirect URL: `http://localhost:3000/index.html`.
2. Запустіть сайт командою `npm run serve:local`.
3. Відкрийте `http://localhost:3000/` (саме `localhost`, не `127.0.0.1`) і натисніть **Connect Twitch**.

Після авторизації Twitch поверне браузер на `http://localhost:3000/index.html` — головний екран із налаштуваннями лотів. Для продакшену додайте до OAuth Redirect URLs точний URL із `/index.html`.
