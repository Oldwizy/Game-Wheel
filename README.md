# Лохотрон ігор і не тільки 🎰

Простий сайт-рандомайзер, зроблений для української твіч-спільноти. Ідея проста: вводите список ігор (чи будь-яких варіантів), а сайт випадково визначає переможця — через слот-машину, колесо фортуни або батл-рояль з кульками.

## Кому це можна

Абсолютно будь-кому. Користуйтесь безкоштовно як завгодно — єдине якщо будете використовувати на стрімі, буду вдячний якщо згадаєте мене і мій канал "OldWizzz"

Якщо хочете взяти цей код за основу і зробити свою версію — будь ласка, це вітається. Єдине прохання: **змініть хоча б дизайн**, щоб ваша версія не була просто копією один-в-один, а мала своє обличчя.

## Що є на сайті

- **Список ігор** (`index.html`) — додаєте варіанти, вказуєте кількість копій (= більше шансів на перемогу), можна зберігати й швидко відновлювати останні списки.
- **Розіграш** (`draw.html`) — три вигляди на вибір:
  - 🎰 **Слот-машина** — класична рулетка з варіантами.
  - 🎡 **Колесо** — кожна копія гри — окремий сектор; після зупинки можна самому вирішити, прибрати варіант чи залишити його в грі.
  - ⚔️ **Батл-рояль** — кожна гра стає кулькою зі своїм HP (100 + 5 за кожну копію понад першу), кульки штовхаються й б'ються, поки не лишиться одна.
- **Twitch-інтеграція** — можна увійти через Twitch і дати глядачам додавати варіанти в список за бали каналу.

## Як запустити

Production-версія публікується напряму з репозиторію через GitHub Pages. Збірка не потрібна: `index.html` і `draw.html` завантажують нативні ES-модулі з `src/`.

## Локальна розробка

```powershell
npm install
npx playwright install chromium
npm run serve
```

Відкрийте `http://127.0.0.1:4173`. Unit-тести: `npm run test:unit`;
браузерні тести: `npm run test:e2e`; повна перевірка: `npm test`.
Production build не потрібен.

## Структура файлів

| Шлях | Відповідальність |
|---|---|
| `src/core/` | версійований стан, випадковість і чисті правила гри |
| `src/build/` | сторінка формування списку та її DOM-представлення |
| `src/draw/` | координатор раундів і візуалізації Slot, Wheel та Battle |
| `src/integrations/` | Twitch OAuth, API та EventSub |
| `src/shared/` | спільне форматування й кольори |
| `tests/unit/` | швидкі тести чистої логіки та lifecycle-контрактів |
| `tests/e2e/` | браузерні регресійні тести обох сторінок |

`npm`, Vitest і Playwright потрібні лише для розробки та CI; production build відсутній.
